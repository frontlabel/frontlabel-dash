# Shoplabel

Gedraag en denk als een ux stragetist met growth hacker inzichten: Ik bied apps aan via Lightspeed, ik heb een admin omgeving nodig om de apps per stuk in te stellen en te beheren, waarbij meerdere shops in beheer kunnen. De eerste app is een verificatie popup voor 18+. De eerste screenshot zijn de credentials om met de shop te connecten, dat is de eerste schakel om een shop aan te sluiten, vanuit daar kunnen ze apps installeren die wij (frontlabel) nog meer aanbieden. Maar ook via de App Store kunnen ze deze installeren, waarna ze op deze admin omgeving terechtkomen. De stijl moet hetzelfde aan voelen als Lightspeed (zie bijlagen), om herkenbaarheid en vertrouwen te blijven behouden.
